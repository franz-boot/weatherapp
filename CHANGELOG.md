# Changelog

Všechny významné změny v projektu budou dokumentovány v tomto souboru.

Formát vychází z [Keep a Changelog](https://keepachangelog.com/cs/1.0.0/),
a projekt dodržuje [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-01-02

### Přidáno

- ✨ Iniciální import aplikace Snow Forecast
- 📍 Vyhledávání míst s inteligentním autocomplete
- 🌍 Podpora geolokace pro automatickou detekci polohy
- ❄️ 14denní předpověď sněžení
- 📊 Interaktivní grafy s Chart.js (denní + kumulativní sněžení)
- 🔔 Konfigurovatelná upozornění na sníh
- 📧 E-mailové notifikace (EmailJS integrace)
- 🌐 Vícejazyčná podpora (CZ, DE)
- 📱 Responzivní design (mobile, tablet, desktop)
- 🎨 Zimní animované pozadí s padajícím sněhem
- 🗂️ Strukturovaný projekt (HTML, CSS, JS v oddělených souborech)
- 📝 Kompletní README s dokumentací
- 🔧 Konfigurační soubory (.gitignore, package.json)
- 📋 CHANGELOG pro sledování změn

### Technické detaily

- Použito Open-Meteo API pro weather data
- Použito Open-Meteo Geocoding API pro vyhledávání měst
- Chart.js pro vizualizace
- Vanilla JavaScript bez závislostí na frameworku
- CSS s glassmorphism efekty
- Canvas API pro animace
